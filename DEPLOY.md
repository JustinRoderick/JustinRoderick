# Deploying the profile chess board

The board is a Cloudflare Worker (`profile-chess`) with one Durable Object holding the game. You sign in once with GitHub so the Worker knows which clicks are yours. Everything below needs your own accounts, so run it yourself.

## 1. Find your Worker URL

The Worker is served at `https://profile-chess.<your-subdomain>.workers.dev`. Your subdomain is shown in the Cloudflare dashboard under **Workers & Pages → Overview** (right-hand column). If you have never connected Cloudflare to Alchemy on this machine, run `bunx alchemy profile edit` first.

Below, `<worker>` means that full URL with no trailing slash.

## 2. Create a GitHub OAuth App

GitHub → **Settings → Developer settings → OAuth Apps → New OAuth App**:

- Application name: `profile-chess` (anything works)
- Homepage URL: `<worker>`
- Authorization callback URL: `<worker>/callback`

Create it, then **Generate a new client secret**.

## 3. Put the credentials in `.env`

In the repo root (`.env` is git-ignored):

```sh
GITHUB_CLIENT_ID=<client id from step 2>
GITHUB_CLIENT_SECRET=<client secret from step 2>
```

The session-signing secret is generated by Alchemy on the first deploy and kept in its state, so there is nothing to set for it.

## 4. Deploy and point the README at the Worker

```sh
bun install
bun run deploy
```

The deploy prints `url`. Check it matches `<worker>`, then replace the placeholder host in the README:

```sh
sed -i 's#https://profile-chess.YOUR-SUBDOMAIN.workers.dev#<worker>#g' README.md
```

Open `<worker>/board.svg` to check it renders, then commit and push the README.

## 5. Sign in once as the owner

Open `<worker>/login` in the desktop browser you play from and approve the OAuth App. You land back on your profile with a one-year session cookie on the Worker's domain. Clicks from that browser now count as your moves. Clicks from anyone else (or from you when signed out) count as the visitors'.

Sign in again from any other browser you want to play from. `<worker>/logout` signs that browser out.

## Local development

```sh
GITHUB_CLIENT_ID=dev GITHUB_CLIENT_SECRET=dev bun run dev   # serves http://localhost:1337 without touching Cloudflare
./scripts/smoke.sh                                           # plays one move pair against it with browser-click headers
bun run shots shots                                          # rasterizes fixture boards to shots/*.png
```

Sign-in does not work locally with dummy credentials. `scripts/smoke.sh` mints an owner cookie from the local dev secret instead.
